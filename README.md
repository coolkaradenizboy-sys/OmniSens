# 🎯 OmniSens

**One Aim. Every Game.**

OmniSens, farklı oyunlar arasında mouse hassasiyetini (Sensitivity) dönüştürmek için geliştirilmiş ücretsiz bir araçtır.

Valorant'ta kullandığın hassasiyeti CS2, Apex Legends ve desteklenen diğer oyunlara kolayca dönüştürerek oyunlar arasında tutarlı bir nişan alma hissi yakalamana yardımcı olur.

## ✨ Özellikler

- 🎮 Oyunlar arası sensitivity dönüştürme
- 🎯 Kolay ve hızlı hesaplama
- 🖱️ Mouse hassasiyetini korumaya yardımcı dönüşümler
- 🌐 Ücretsiz ve kolay erişilebilir arayüz
- ⚡ Basit ve kullanıcı dostu tasarım

## 🕹️ Nasıl Kullanılır?

1. Hassasiyetini dönüştürmek istediğin oyunu seç.
2. Mevcut sensitivity değerini gir.
3. Hedef oyunu seç.
4. Dönüştürülmüş hassasiyet değerini görüntüle.

## 🌍 Proje

OmniSens, oyuncuların farklı oyunlara geçerken alıştıkları mouse hassasiyetini korumalarına yardımcı olmak amacıyla geliştirilmiştir.
